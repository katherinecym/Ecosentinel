## 🌟 Overview & Key Innovations

EcoSentinel couples hydro-morphological dynamics, causal machine learning (Double Machine Learning / DML), and graph neural networks to predict vector mosquito outbreaks and assess Nature-based Solutions (NbS) interventions.

1. **Physics-informed Causal Inference**: Identifies dissolved oxygen (DO) and stream baseflow thresholds that suppress vector breeding while promoting aquatic biodiversity.
2. **Topological Stream Network Modeling**: Evaluates river reach connectivity and upstream-downstream cascading impacts.
3. **Public Health & DALY Valuation**: Computes Population-at-Risk (PAR) and economic benefits of targeted ecological restorations.

## 🏃 Running the Dashboard Locally

You can launch the decision-support dashboard in less than a minute:

```bash
# 1. Clone the repository
git clone https://github.com/katherinecym/Ecosentinel.git
cd Ecosentinel

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch Streamlit
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.

## ☁️ Deploying to Streamlit Cloud (1-Click)

To let anyone access the live dashboard via a public URL:
1. Log in to [Streamlit Community Cloud](https://share.streamlit.io/) with your GitHub account.
2. Click **"New app"**.
3. Select this repository: `katherinecym/Ecosentinel`.
4. Set Main file path: `app.py`.
5. Click **"Deploy!"** — your dashboard will be live with a shareable public URL.
