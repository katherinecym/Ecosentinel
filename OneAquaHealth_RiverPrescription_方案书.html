0 · 先给结论

做

把「处方」做成产品

官方生态里缺的是定量决策层：剂量、疗效、受众、成本、置信度。这不是又一个地图，是地图下面那一层。

敢

敢说「这条不成立」

我们的因果检验显示：溶氧显著（p=0.0045）、流速不显著（p=0.36）。据此我们建议城市不要单独为流速花钱。这一句话比任何可视化都值钱。

改

换一个视角：点 → 线

官方是地图视角（一堆点）。河流是线性系统，天然视角是纵向剖面——上游一个动作如何传到下游，只有「线」能讲清。

险

最薄弱的一环

我们的 85 站点城市标签与官方 5 个示范城市只重合 2 个。这条必须在提交前澄清，否则直接威胁 30% 权重的 Impact 项。

3 · 新方案：RiverPrescription

3.1 定位：三条轴上的差异

点 → 线

官方看「点」：地图上撒站点。
我们看「线」：河流是线性系统，纵向剖面才是它本来的样子。 上游一个动作怎么传到下游、哪一段是瓶颈，只有剖面能回答。

现在 → 如果

官方看「现在」：指标快照。
我们看「如果」：拖动干预，看 30 天羽化、2050 气候、人群风险与成本一起变。 把地图变成风洞。

措施 → 剂量 + 价钱 + 置信度

官方给「措施」：有哪些办法。
我们给「剂量」：把溶氧抬到 6.5 mg/L（不是「加强曝气」）， 外加疗效、受众、€ 和一张证据价签。

3.2 核心创新：证据价签

这是整个方案里最应该被记住的东西。城市不是缺建议，是缺知道哪条建议值得信。 所以每一欧元都配一个等级：

等级含义本项目实例证据
A · 因果已证 准实验级证据，跨城聚类稳健，区间不跨 0 溶氧 → 媒介风险 DML β = −0.2818 / +1 mg/L，p = 0.0045，CI [−0.418, −0.146]，5 城聚类稳健，H1 正式检验通过
B · 关联未证因果 点估计可观但区间跨 0 流速 → 媒介风险 β = −0.3512 / +0.1 m/s，p = 0.3623，CI [−1.300, +0.598]
C · 机制情景 文献参数化机制模型，非实测干预 30 天羽化 −17.07% Brière ODE，参数来自文献，官方也把 30 天预测定位为机制情景
D · 生态代理 宏观对齐，仅探索 ECDC 病例对齐 Spearman ρ = 0.80，p = 0.104，n = 5
它产生的第一个可交付结论： 「把钱花在溶氧上（A 级）；不要单独为流速投资（B 级）。 若要动流速，请把它当作溶氧措施的附带收益，而不是独立预算项。」 —— 一句有证据、可审计、能直接进预算会的建议。这是 30% Impact 分最实在的来源。

3.3 四个创意机制

机制一 · 一张数据三张脸

同一次计算，三种抽象层级，切换不改数字：
· 市民脸「今天能下水玩吗？」
· 市政脸85 站告警名册 + SOP + 预算
· 科研脸全指标 + 模型卡 + 不确定性 + 导出
这直接解决「太抽象、对普通群众不友好」的老问题，而且不牺牲专业深度。

机制二 · 敢说不知道

每个输出带证据徽章；情景一旦超出训练域，系统拒绝外推并说明为什么。
训练域实测：溶氧 2.09 – 7.19 mg/L。
所以「把溶氧调到 9 mg/L」这种输入，产品不给答案—— 因为它没有证据。把认识论诚实做成产品功能，是这次最容易记住的差异点。

机制三 · 纵向剖面视图

把一条河画成从左（上游）到右（下游）的剖面，风险、溶氧、告警等级沿程铺开。 用我们已有的 river_or_channel_id + reach_distance_m 直接构造。 比地图上一堆针脚更能回答「该在哪一段动手」。

机制四 · 活在官方生态里

读：官方 API 读取端点无需鉴权（已实测），可实时拉取健康风险、城市参数、天气、公民点位。
写：把「媒介风险 + 干预建议」作为一个新图层回写 OIH。
复用：官方《Catalogue of Measures》作为措施库（我们已有 PDF）。
我们做一层，不重造一个平台——这正是 Feasibility 项要的「与既有系统集成」。

5 · 风险与诚实披露

高 · 城市口径

85 站点的城市标签与官方示范城市只重合 2 个。这是唯一可能直接击穿 Impact 项的问题。处理方式只有两种：拿到真实出处，或改写叙事。

中 · 成本假设

€255,000 五城平摊，导致回收期排序主要由成本驱动而非效益驱动。至少要给出成本敏感性区间。

中 · 离线可用性

现有四个看板屏蔽 CDN 后完全失效。新交付物必须零外部依赖——这既是风险也是最容易兑现的加分项。

我们已经主动披露过的技术局限（延续既有审计口径）
  • 流速因果不显著（p = 0.3623）——写成因果会过度解读。
  • H3 未能拒绝 H0（p = 0.3125）——河网拓扑没有可迁移增益，五城河网全是简单链。
  • 不支持 0.30 m/s 硬阈值——H2 的局部线性阈值对比 p ≈ 0.34，只有组间关联，不是阈值效应。
  • 30 天羽化是机制情景，不是实测干预效果。
  • PAR 是暴露量不是人数——500 m 缓冲区互相重叠，不能读成「保护了 7,913 个不同的人」。
  • 老年人未获得差异化保护——风险模型没有年龄项，65+ 的相对削减是构造出来的。
  • ECDC 对齐是生态代理（ρ = 0.80，p = 0.104，n = 5），仅探索性。
  • MAUP：250 m / 1000 m 半径下的人口是按面积缩放代理，不是真实人口网格，无法估计尺度效应。
